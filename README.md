# Komentář k zákonu č. 181/2007 Sb., o Ústavu pro studium totalitních režimů a o Archivu bezpečnostních složek a o změně některých zákonů

Otevřený komentář k zákonu o Ústavu pro studium totalitních režimů a o Archivu bezpečnostních složek — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; preambule, úkoly Ústavu, Rada Ústavu a ředitel, Archiv bezpečnostních složek, převzetí a zpřístupnění dokumentů, spolehlivost a bezúhonnost a změny souvisejících zákonů.
